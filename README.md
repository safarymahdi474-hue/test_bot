# ربات تست و کنکور (تلگرام)

## نصب

```bash
pip install -r requirements.txt --break-system-packages
```

## تنظیمات (متغیرهای محیطی)

```bash
export BOT_TOKEN="توکن ربات از @BotFather"
export ADMIN_IDS="123456789,987654321"   # آیدی عددی ادمین‌ها، با کاما جدا
```

## اجرا

```bash
python bot.py
```

دیتابیس (`bot_data.db`، فایل SQLite) خودکار در همون پوشه ساخته می‌شه.

## افزودن سوالات تست (عکسی)

سوال‌ها و پاسخ‌نامه به‌صورت **عکس** ذخیره می‌شن (نه متن)، چون خیلی از سوال‌ها نمودار/فرمول دارن. دو روش:

1. **تکی و گام‌به‌گام**: پنل مدیریت → «📝 مدیریت تست‌ها» → «➕ افزودن تست (با عکس)».
   پایه/رشته/درس/کتاب/فصل/شماره رو متنی می‌پرسه، بعد عکس سوال رو می‌خوای، بعد پاسخ صحیح (۱ تا ۴)، بعد اختیاری عکس توضیح/پاسخ‌نامه.

2. **آپلود دسته‌جمعی (ZIP)**: پنل مدیریت → «📤 آپلود دسته‌جمعی (ZIP)».
   یه فایل ZIP بفرست شامل:
   - `manifest.xlsx` یا `manifest.csv` با ستون‌ها: `پایه | رشته | درس | کتاب | فصل | شماره | پاسخ | فایل_سوال | فایل_توضیح`
   - عکس‌های سوال/توضیح با همون اسمی که توی manifest نوشتی (مثلاً `q5.jpg`)

   ربات هر عکس رو به چت خودت (ادمین) می‌فرسته تا `file_id` بگیره، بعد توی دیتابیس ثبتش می‌کنه.

## افزودن امتحان نهایی

از پنل مدیریت → «📝 مدیریت امتحان نهایی» → «➕ افزودن امتحان نهایی»:
پایه → رشته → درس رو انتخاب می‌کنی، بعد یه عنوان می‌نویسی (مثلاً «نوبت دوم - خرداد ۱۴۰۲») و فایل رو می‌فرستی.
هر درس می‌تونه چند امتحان (سال/نوبت مختلف) داشته باشه؛ همه با همون عنوان‌ها لیست می‌شن.

## تنظیم کانال اخبار

از پنل مدیریت → «📢 تنظیم کانال اخبار»، عنوان و لینک رو به فرمت `عنوان | لینک` بفرست.
دکمه‌ی «📢 کانال اخبار» در پنل اصلی این لینک رو نشون می‌ده.

## افزودن فایل کتاب به کتابخانه

فایل (PDF و…) رو مستقیم به ربات بفرست با کپشنی به این فرمت:

```
پایه | رشته | درس
دهم | علوم تجربی | ریاضی
```

## افزودن سوالات تست

سه روش:
1. **تکی و گام‌به‌گام** از پنل مدیریت → «📝 مدیریت تست‌ها» → «➕ افزودن تست»
2. **آپلود اکسل** با همون پنل → «📤 آپلود فایل Excel» (ستون‌ها در راهنمای داخل ربات نوشته شده)
3. مستقیم در دیتابیس از طریق توابع `database/content.py`

## نکات مهم پیاده‌سازی

- **سوالات و پاسخ‌نامه به‌صورت عکس هستن**، نه متن (به‌خاطر نمودار/فرمول‌های زیاد در تست‌های کنکور). فقط «شماره گزینه‌ی صحیح» به‌صورت عدد ذخیره می‌شه تا نمره‌دهی خودکار انجام بشه.
- امتیاز فقط برای اولین پاسخ صحیح به هر سوال داده می‌شه؛ اگه کاربر پاسخش رو عوض کنه، امتیاز به‌درستی اصلاح می‌شه (نه تکراری، نه گم).
- وقتی چند نفر یک سوال رو گزارش می‌دن، ادمین یک‌بار (گروه‌بندی‌شده) می‌بینه، نه هر گزارش جدا.
- اصلاح سوال توسط ادمین به‌صورت اتمیک با ثبت لاگ (`question_edit_log`) انجام می‌شه.
- ریست امتیاز هفتگی خودکار هر جمعه ساعت ۲۳:۵۹ اجرا می‌شه (نیازمند اجرای مداوم ربات).
- تمام لایه‌ی دیتابیس با تست واقعی (نه فقط syntax check) تأیید شده — پوشه‌ی `tests_manual` رو ببین.
